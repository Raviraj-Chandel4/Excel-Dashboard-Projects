# 🎬 Movie Performance Dashboard

## 📌 Project Overview

The **Movie Performance Dashboard** is an interactive Power BI dashboard designed to analyze movie industry performance using key financial and production metrics.

The dashboard enables users to explore:
- Revenue and profit trends
- Return on Investment (ROI)
- Genre-wise performance
- Director-wise ROI analysis
- Movie release trends over time
- Budget vs Revenue relationships

This project helps stakeholders identify the most successful movies, profitable genres, and high-performing directors for data-driven decision making.

---

## 🎯 Business Questions Answered

- How many movies are included in the dataset?
- What is the total revenue generated by all movies?
- What is the total profit earned?
- What is the overall ROI percentage?
- Which movies generated the highest revenue?
- Which genres contribute the most revenue?
- How has movie production changed over the years?
- Which directors delivered the highest ROI?
- What is the genre distribution across all movies?
- Is there a relationship between movie budget and revenue?

## 📈 Dashboard Visualizations

### 1. Top 10 Movies by Revenue
Displays the highest-grossing movies in the dataset.

### 2. Revenue by Genre
Analyzes revenue contribution across movie genres.

### 3. Movies Released by Year
Shows yearly movie release trends.

### 4. Top 10 Directors by ROI
Highlights directors with the highest return on investment.

### 5. Genre Distribution %
Represents the proportion of movies across different genres.

### 6. Budget vs Revenue Analysis
Scatter plot used to examine the relationship between production budget and generated revenue.

---

## 🎛 Interactive Filters

The dashboard includes dynamic slicers for:

- Movie Title
- Genre
- Release Year
- Director

Users can filter the entire dashboard to perform detailed analysis.

---

## 🔍 Key Insights

- Action movies generate the highest overall revenue.
- ROI varies significantly among directors.
- Most movies are concentrated within a few dominant genres.
- Higher budgets generally lead to higher revenues, though exceptions exist.
- Certain directors consistently achieve exceptional returns on investment.
